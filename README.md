## How is IPO GMP Calculated?

GMP is commonly discussed as a premium over the IPO issue price.

### Example

**Issue Price:** ₹150

**GMP:** ₹30

**Estimated Listing Price = ₹150 + ₹30 = ₹180**

The implied gain based on this calculation would be:

**₹30 ÷ ₹150 × 100 = 20%**

This is only an illustrative calculation. The actual listing price can be different from the GMP-based estimate.
